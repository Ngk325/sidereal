    How this is calculated
    

      
Each moment's angle is its local sidereal time: Julian day → Greenwich mean sidereal time → plus longitude. Sidereal time gains about four minutes a day on clock time, so the figure drifts even at the same wall-clock hour.

      
Rotational orders, chord counts, spokes, petals and rings come from digit sums of each date. When both moments are in use, the great-circle arc between the two places rotates the present layer out of register, and each latitude shears its own flow field.

      
The cipher is a real, reversible stream cipher. A 32-bit key is hashed from the moments' sidereal angles, coordinates and digit roots, then run through a deterministic generator to produce a keystream that shifts each character. The glyph ring plots the ciphertext: one mark per character, its length encoding the value. It is a puzzle, not security — don't use it for anything that must stay secret.

      
The transmission — the dark panel — is different in kind. It is generated by indexing fixed word banks with the computed values: the same numbers always produce the same words. It is a decoding convention this piece defines, not a message recovered from the sky.
